# VikingViewer

Lightweight viewer for Viking Scoring, built with vanilla JavaScript and Node.js 22+. No external dependencies.

## Start

1. Copy `.env.example` to `.env` and enter your local network credentials.
2. On Windows, run `start.bat` to connect network drives and open the viewer.
3. Alternatively, run `npm start` when network drives are already connected.

Run `npm test` for tests. See [README.txt](README.txt) for the complete Norwegian setup and usage guide.

Local `.env` and `settings.json` files are excluded from Git.
