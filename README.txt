VikingViewer

Dokumentasjonen er samlet i README.md.
Apne den lokalt i en Markdown-leser, eller les den pa GitHub:
https://github.com/jogyth/VikingViewer#readme

Hurtigstart:
1. Installer Node.js 22 eller nyere.
2. Kopier .env.example til .env og fyll inn lokal palogging.
3. Start start.bat pa Windows.

Alternativ serverstart: npm start
Tester: npm test
